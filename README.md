# egrkn-altai-repro

Код и производные данные для воспроизведения проверки соответствия федерального реестра объектов культурного наследия (ЕГРОКН) и краевого списка объектов культурного наследия Алтайского края. Пилотные районы: Змеиногорский, Красногорский, Солтонский.

Репозиторий сопровождает статью Г. З. Папашвили и А. Д. Дерендяевой; библиографическое описание будет добавлено после публикации.

## Быстрая проверка

Python 3.12 (проверено). Сверка контрольных значений по файлам `data/derived/`:

```
pip install -r requirements.txt
pip install pytest
python src/run_all.py --check
pytest tests/test_reproduce.py
sha256sum -c CHECKSUMS.sha256
```

`run_all.py --check` завершается строкой `ВСЕ СОВПАЛО`, тесты — без ошибок, `sha256sum` — без расхождений.

## Полная перегенерация

`python src/run_all.py --inputs inputs` перегенерирует `data/derived/` из входных файлов. Состав входных файлов, порядок шагов и команды — в [REPRODUCE.md](REPRODUCE.md).

| 7. Геоконтроль пилотных районов | `s07_geo_control.py` | `geo_diagnostics.csv`, `geo_boundary_distances.csv` | табл. 4, рис. 1 |

## Контрольные значения

`python src/run_all.py --check` сверяет: 4518 записей в выборке и 4516 по региону; в краевом списке 2204 записи, из них 2201 найдена в реестре; 2200 записей реестра из 4516 присутствуют в списке; район установлен у 2131 записи, не установлен у 2385; в пилотных районах 99 записей реестра (67 / 19 / 13), из них 97 в списке (65 / 19 / 13); координаты у 12 записей, все внутри своего района; 39 записей без района имеют координаты; регистрационных номеров списка с утраченным нулём 47, восстановлено 46; расхождение наименований у 95 из 2198 пар, сходство ниже 0,60 у 18 пар; 102 различия между версиями определения района; контрольные суммы `86afa4ab…` (регистрационные номера) и `8734de19…` (районы).

## Методические замечания

Расстояние от записи до границы района вычисляется в локальной азимутальной эквидистантной проекции на эллипсоиде WGS 84 (`pyproj`). Минимум по 12 записям Змеиногорского района составляет 6707,864 м (запись E02493), ближайшая точка границы совпадает с вершиной полигона.

Интервалы Уилсона (95%) и z-критерий для разности долей (с объединённой оценкой) реализованы в `src/s08_metrics_tables.py`. Группы в таблице 4: «мемориалы ВОВ» — первая типология «Памятник истории» и признак `wow_value` = «Да»; «прочие памятники истории» — та же типология без признака; «градостроительство и архитектура» — первая типология «Памятник градостроительства и архитектуры». Содержательная датировка — поле `general.createDate`, непустое и не содержащее «не определена».

Рисунки строятся скриптом `s10_figures.py` по файлам данных; побитовое совпадение PNG между версиями matplotlib и шрифтов не гарантируется, числа на рисунках выводятся в консоль и сверяются с таблицами. Скрипт `s10_figures.py` и рисунки в `CHECKSUMS.sha256` не входят.
