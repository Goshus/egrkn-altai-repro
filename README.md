# egrkn-altai-repro — воспроизводимый репозиторий исследования ЕГРОКН-Алтай

Репозиторий воспроизводит процедуру сопоставления Государственного реестра объектов культурного наследия (ЕГРОКН) и краевого списка ГУКН Алтайского края, описанную в статье «[название статьи — не установлено]» (авторы: Георгий Папашвили, Анна Дерендяева).

## Цитирование и авторство

При использовании этого репозитория или производных от него материалов в исследовании сошлитесь, пожалуйста, на статью авторов — Георгия Папашвили и Анну Дерендяеву (полное библиографическое описание будет указано в `CITATION.cff` после публикации; до неё в качестве предварительной ссылки приводите репозиторий https://github.com/Goshus/egrkn-altai-repro и авторов). Просьба сохранять авторство: исходный код пайплайна распространяется под лицензией MIT, авторская документация и ручная разметка — под CC BY 4.0 (см. `LICENSE` и `LICENSE-DATA`), а условия сторонних данных (ЕГРОКН, краевой список, OSM) приведены в `THIRD_PARTY.md` и сохраняют приоритет.

## Назначение

Скрипты в `src/` порождают каждое число, таблицу или рисунок статьи (принцип аналитической достаточности). Рабочие отладочные скрипты, промты, отчёты заходов и одноразовые правки исключены (см. раздел «Исключённое» ниже).

## Порядок запуска

```
python src/run_all.py --inputs ./inputs    # перегенерация derived из входных дампов
python src/run_all.py --check              # приёмка замороженных derived-файлов
```
`--inputs DIR` ожидает в `DIR`: `1.json`…`17.json` (дамп ЕГРОКН), `Spisok…md` (краевой список), перечень ОКТМО `.docx`, `boundary_1..3.json`. Дамп и PDF в репозиторий не входят — их состав и sha256 см. в `data/input_manifest/manifest_dump.csv`.

## Контрольные значения (приёмка)

`python src/run_all.py --check` сверяет: 4518/4516; 2204; 2201 из 2204; 2200 из 4516; район не установлен 2385 (2131 назначено); полигон 97 из 99 (67/19/13; 65/19/13); 12/0/0 с координатами; 39 без района с координатами; 47 и 46; 95 из 2198; 18 ниже 0,60; sha256 86afa4ab… и 8734de19…. Минимальное расстояние до границы: локальная азимутальная эквидистантная проекция (AEQD), эллипсоид WGS 84 — 6707,864 м (E02493, заход 14); (а) вершины = (б) отрезки (ближайшая точка границы — вершина); условие (б) ≤ (а) для всех 12. Разница с заходом 13 (6693,266 haversine / 6699,120 equirect): смешение двух метрик — сферическая haversine (R=6371000) vs equirect planar (искажение по долготе); AEQD на эллипсоиде WGS84 даёт истинное геодезическое (~14,6 м больше haversine из-за сфера-vs-эллипсоид).

## Статистика

Интервал Уилсона и z-критерий реализованы в `src/s08_metrics_tables.py` (`wilson_ci`, `z_test_two_props`). Заход 13: таблица 3 и таблица 4 статьи воспроизведены полностью (`data/derived/table_3_field_completeness.csv`, `table_4_groups.csv`), включая z: −12,8; −18,0 (все записи с адресом); 2,3; −0,5 (мемориалы ВОВ = «Памятник истории» + wow_value); 0,8; −6,6 (прочие памятники истории); −9,8; −10,6 (градостроительство и архитектура). Группы: сельские vs городские; «Мемориалы ВОВ» — первая типология «Памятник истории» и wow_value=«Да» (поле wow = принадлежность к ВОВ); «датировка (содержательная)» — general.createDate непустое и не «не определена».
