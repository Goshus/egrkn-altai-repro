# legacy/ — прежние версии

Материалы предыдущих версий скриптов и таблиц. В схему воспроизведения (`src/`) не входят.

- `district_detector_v2.py` — прежняя версия определения района (поиск основы названия как подстроки сегмента адреса); назначает 2103 района. Текущая версия — `src/s06_assign_districts.py` (2131 район).
- `egrkn_altai_full_v2_districts.csv` — результат `district_detector_v2.py`.
- `v2_v3_diffs.csv` — сравнение результатов двух версий: 102 различия (34 района назначены только в текущей версии, 6 — только в прежней, 62 — назначены по-разному).
